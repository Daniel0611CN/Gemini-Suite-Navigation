Gemini Suite Navigation

All organization data stays in this browser. The extension does not use analytics or remote services.

Custom shortcuts

Use the same format as a browser shortcut, for example Alt+Shift+G. Chrome-managed commands can also be changed at chrome://extensions/shortcuts.

Compatible domains

Local backup

Backups include organization, favorites, tags, recent items, and settings. Conversation contents are never uploaded.

Release and privacy

Installable builds are distributed only as versioned ZIP files attached to GitHub Releases. See the repository README and permissions documentation for details.
