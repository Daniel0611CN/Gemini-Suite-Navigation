# Permissions and privacy

The extension stores organization metadata, settings, favorites, tags, and backups locally through Chrome storage. It does not send conversation data, analytics, or telemetry to an external server.

The `storage` permission is used for local settings and organization data. `activeTab` supports actions on the active Gemini or AI Studio tab. Host access is limited to the configured Google API endpoint used by the existing optional organizer/export features. Optional API-key functionality remains user initiated and is not required for navigation, search, backups, or settings.
